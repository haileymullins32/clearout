What Clearout does with your data, and how to keep it private if this device isn't only yours.

The short answer

Nothing you type into Clearout is ever sent anywhere. There's no server, no account, no analytics, and no company on the other end of this collecting anything. Your name, addresses, phone numbers, and emails are saved only inside this browser, on this device — that's the entire extent of where your data lives.

How your data is actually stored

Everything you enter is saved using a browser feature called localStorage — think of it as a small file the browser keeps for this specific site, on this specific device. It is:

  • Never transmitted. Clearout's code makes exactly one network request — loading its own list of broker sites — and nothing else. Nothing you type is included in any request, ever.
  • Local to this browser. It doesn't sync to your account, to other browsers, or to other devices, unless you explicitly use the Export my data button and move that file yourself.
  • Gone if you clear it. Clearing your browser's site data, or using a private/incognito window, removes it — which is a feature, not a bug, on a device you don't want to leave a trace on (see below).

The one real risk: shared devices

localStorage is shared by anyone using the same browser on the same computer — it doesn't know who's sitting at the keyboard. If someone else opens Clearout in that same browser later, they'd see whatever profile was last saved there, the same way they'd see saved autofill or a logged-in email account.

Only use Clearout on a device you own and control, that isn't shared with people you don't know and fully trust — not a library computer, a work or school shared machine, a hotel business center, or a friend's device where other people also have access.

How to keep it private

  1. Stick to a personal device. Your own phone, laptop, or desktop — one only you (and people you'd trust with your address and phone number) can log into.
  2. If you must use a shared or public computer, use a private/incognito window. Data saved there is automatically thrown away when you close the window, so nothing lingers for the next person. The tradeoff is that Clearout won't remember your progress between sessions — use Export my data before you close the window if you want to pick up where you left off later.
  3. On a shared device you use regularly, clear this site's data when you're done (in most browsers: Settings → Privacy → Clear browsing data, or right-click the page → Inspect → Application → Clear site data). A private window is easier if you have the option.
  4. Treat exported backup files like the personal document they are. The file from Export my data contains everything in your profile in plain text. Save it somewhere only you can access, and don't leave a copy sitting in the Downloads folder of a computer that isn't yours.
  5. There's no login, so there's no "logging out." Anyone with access to your unlocked device and browser can open this page and see what's saved. Lock your device the way you normally would.

What can the person who published this page see?

If you're using a copy of Clearout someone else hosts (including its own GitHub Pages site), the same guarantee applies: the app has no backend to send data to, so its host — including us — has no way to see what you type, how many people use it, or anything else about your session. A host can typically see ordinary web server logs (like which pages were requested and roughly when), the same as any website, but never form content, since none is ever sent. If you'd rather not rely on someone else's copy at all, Clearout is designed to be trivial to self-host — see the README for plain-language instructions.
